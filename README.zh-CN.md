## 由整体，深入内部

打开细胞，进入细胞器，再沿着结构层级走向分子尺度。旋转、剖视或拆解模型，看清各部分如何连接。

![中文界面中的动物细胞结构探索](docs/media/zh/structures.jpg)

## 让过程变得可见

观察转录如何进行，追踪光合作用中的能量转化，跟随肽链逐步延长。逐步查看、随时暂停，再回到相关结构，理解过程发生的原因。

![转录：沿模板持续延伸](docs/media/zh/transcription.jpg)
