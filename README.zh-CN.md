## 留下自己的观察

**并排比较。** 将两个模型放在一起，分别调整视角、剖面、标签与拆解状态。对比说明标明各自代表的生物学范围；两侧画面独立适配，不使用统一的真实比例尺。

**影像创作。** 在影像工作台中选择横版、竖版或方形构图，导出可带透明背景的 PNG，也可以把旋转、拆解或生命过程录成短片。

**继续与分享。** 从主页接着上次的场景探索。通过链接分享模型、进行中的过程或双模型对比，保留视角与显示设置。

## 关于模型

BioScape 用于生物学探索与教学。各模型附有适用范围、说明和参考资料；几何形态、比例与时间经过教学简化，实验结构单独注明来源。

[科学审查](docs/science-audit/acceptance/README.md) · [验证范围](docs/science-audit/acceptance/VALIDATION.md) · [第三方声明](docs/legal/THIRD_PARTY_NOTICES.md)

需要 Node.js 22.12 或更新版本：

```sh
npm ci
npm run dev
```

发布前运行 `npm run check`。
