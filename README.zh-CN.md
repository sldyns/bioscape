## 从整体，到内部

[![BioScape 结构探索界面：左侧层级目录，中间交互模型，右侧结构说明](docs/media/structure-overview.jpg)](https://sldyns.github.io/bioscape/#/cell)

- **逐层进入。** 点击模型或目录中的结构，继续查看它的内部。例如「细胞核 → 染色质 → 核小体 → DNA」。
- **换个角度理解。** 旋转、缩放，在适用结构中切换整体、剖面与拆解视图。
- **始终知道身在何处。** 目录随层级更新，顶部路径可返回任意一级，不必重新开始。

## 从结构，到活动

[![转录过程界面：步骤目录、三维模型、可拖动时间轴与讲解](docs/media/transcription.jpg)](https://sldyns.github.io/bioscape/#/cell?view=process&process=transcription)

过程可以播放，也可以暂停细看、拖动时间线，或直接跳到某一步。部分过程提供条件对照，还能进入相关结构继续探索。

| 想了解什么             | 可以从这些过程开始                           |
| ---------------------- | -------------------------------------------- |
| **遗传信息如何传递**   | DNA 复制、转录、RNA 加工、核糖体翻译         |
| **基因如何被调控**     | 启动子、增强子、染色质可及性、染色质环与 TAD |
| **能量与物质如何流动** | 光合作用、呼吸作用、跨膜运输、蛋白质分泌     |
| **细胞如何活动与响应** | 细胞分裂、信号传递、微生物生活史、噬菌体侵染 |

[**进入生物学过程目录 →**](https://sldyns.github.io/bioscape/#/cell?view=process)

## 自由探索，随时分享

| 操作                 | 效果                       |
| -------------------- | -------------------------- |
| 拖动 / 滚轮          | 旋转 / 缩放模型            |
| 点击模型部件或目录项 | 进入对应结构               |
| 时间轴 / 步骤目录    | 拖动过程，或跳转到指定步骤 |
| 中文 / EN            | 保留当前位置，切换语言     |
| 复制页面地址         | 分享当前结构或过程         |

也提供触屏手势与缩放按钮。精细模型建议在支持 WebGL 2 的电脑浏览器中观看。

## 模型与科学语境

BioScape 是教学可视化作品。颜色、比例、时间和分子数量经过简化，以便看清关系；剖面、拆解与局部放大是观察方式，不代表结构真实分离。使用实验坐标的模型会标明来源与范围，示意动画不等同于原子级模拟。

模型内附有相应说明与参考资料。审查与验证方法见[科学审查总表](docs/science-audit/acceptance/README.md)、[验收范围](docs/science-audit/acceptance/VALIDATION.md)与[第三方来源](THIRD_PARTY_NOTICES.md)。

## 本地运行

需要 Node.js 22，版本见 [.nvmrc](.nvmrc)。

```sh
git clone https://github.com/sldyns/bioscape.git
cd bioscape
npm ci
npm run dev
```

```sh
npm run check    # 格式、完整回归、生产构建与发布检查
npm run preview  # 本地预览生产构建
```
