# Cell Atlas 生物学过程与调控场景规划

更新：2026-09-19。本文是候选内容与实施顺序分析，不代表这些模型已经实现。

## 当前起点

代码中已有四个独立过程：真核 RNA 聚合酶 II 转录、经典可溶性蛋白分泌、光合作用概览、T4 机制示例的侵染起始阶段。最后一项还没有复制、组装或裂解，也不是 λ 噬菌体的溶原周期。

现有生物入口为动物细胞、植物细胞、细菌、真菌（出芽酵母示例）、草履虫、噬菌体。下述“共同过程”表示基本原理可比较，不表示分子组成、发生位置和调控方式相同。

优先补齐两条学习线：DNA → RNA → 蛋白质；环境信号 → 基因调控 → 细胞行为。另以物质运输和能量转换，把静态细胞器连接成有因果关系的系统。

## 如何决定什么值得做

每个候选都考察六点：学习价值、三维空间是否有助于理解、是否有明确可操作变量、证据是否足够、能复用哪些现有结构、是否需要新增细胞类型。

- 三维收益高：核糖体翻译、膜融合、ATP 合酶、纺锤体、染色质环挤出、纤毛运动。
- 三维与二维联动更合适：TAD 与接触矩阵、膜电位与电压曲线、酶反馈与代谢流量、基因开关与表达时间序列。
- 通路节点很多时用反应图呈现联系，选关键反应做三维放大。糖酵解十步不必全部制成分子碰撞动画。
- 细胞级模型不能代替组织：神经传递需神经元，气孔需保卫细胞，向光性需组织，免疫需相应免疫细胞。

优先级：A 为下一轮核心；B 为核心建立后的扩展；C 为专门细胞、组织或研究层面的专题。优先级是产品判断，不是生物学重要性排名。

## TAD 专题怎样做才有价值

TAD（拓扑关联结构域）描述的是沿基因组一段区域内部相对更频繁的空间接触。它不是核内有膜包围的细胞器，也不是在所有细胞、每个时刻都保持一样的固定球体。

建议把学习顺序做成：DNA 上的启动子和增强子 → 因子结合 → 染色质局部可及性 → 远距离调控 → 环挤出和边界 → 多个构象的统计接触图。这样用户先知道为什么要接触，再理解三维组织。

一个完整交互单元包含：

1. **定位**：一条有基因、启动子、增强子与边界标记的线性基因组；选中后在三维链上同步定位。
2. **观察**：播放一组动态构象，cohesin 推动环挤出；CTCF 位点用方向箭头表示。三维链旁显示小型接触矩阵。
3. **扰动**：正常、特定位点反向、边界缺失、cohesin 缺失四个预设。不要让用户随便拖近两个点就得到“基因必然开启”。
4. **比较**：并排展示接触分布及一个有证据的表达案例。几何接触概率和转录产出分开显示；示意模型不输出伪精确的表达倍数。
5. **证据**：标明构象是机制示意还是来自特定实验数据。Hi-C/Micro-C 图是接触频率，不是单个细胞的三维照片；一个接触矩阵不能唯一决定一条真实构象。

环挤出有直接的单分子实验支持，但 CTCF 屏障的作用还受条件影响，不能画成完全不可穿越的墙。[Davidson 等：human cohesin loop extrusion](https://pmc.ncbi.nlm.nih.gov/articles/PMC7387118/)、[CTCF 屏障实验](https://www.nature.com/articles/s41586-023-05961-5)。

边界改变可在特定位点重排增强子—基因关系，适合采用 EPHA4 相关研究作为进阶案例；但去除环结构并不意味着所有基因表达都大幅改变。[边界扰动研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4791538/)、[cohesin 去除实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC5846482/)。

植物不能直接使用哺乳动物的 CTCF/cohesin 解释模板。水稻、拟南芥等植物的结构域表现不同；高分辨率植物数据也能揭示局部染色质组织和增强子—启动子联系。应另做物种明确的对照版本。[水稻与拟南芥比较](https://www.nature.com/articles/s41477-017-0005-9)、[植物 Micro-C-XL 研究](https://www.nature.com/articles/s41467-023-44347-z)。

| E02 | 丙酮酸氧化与三羧酸循环 | 追踪 CO₂、NADH/FADH₂ 与碳骨架 | B；区分真核区室与细菌位置，不做成实际圆形管道 |

| E07 | 酶的反馈调节 | 添加终产物、观察关键酶与通路流量改变 | B，适合二维反应图加三维酶局部 |
| M01 | 扩散与协助扩散 | 改变浓度差、分子种类、通道开放条件 | A；展示净通量和双向随机运动，不只单向排队 |
| M02 | 渗透与细胞体积 | 改变外液渗透条件，比较动物与有细胞壁的细胞 | A；固定明确的溶质通透性和时间尺度 |

| M04 | 受体介导胞吞 | 追踪配体、受体、包被、内体分选与回收 | A，选动物细胞经典案例；不把所有胞吞都画成吞噬 |

| M06 | 自噬与细胞器回收 | 选择待回收结构，观察包裹与降解 | B；动物溶酶体和植物/酵母液泡终点不同 |
| M07 | 马达蛋白运输 | 观察沿微管的步进、方向与囊泡货物 | B；不同马达的方向和骨架类型须明确 |

ATP 合酶特别适合做跨模型比较：同一能量转换原理发生在不同膜与区室中。[NCBI：Energy Conversion](https://www.ncbi.nlm.nih.gov/books/NBK21063/)、[Chloroplasts and Other Plastids](https://www.ncbi.nlm.nih.gov/books/NBK9905/)。

| U01 | 酵母出芽 | 追踪芽位、核分配、颈部及分离 | A，与动物缢裂和细菌二分裂对照；出芽酵母通常闭合式有丝分裂 |
| U02 | 酵母交配与生活史 | 比较交配型、细胞融合和倍性变化 | C；需要两个细胞，环境和倍性影响后续过程 |
| U03 | 草履虫纤毛运动 | 放大 9+2 轴丝，联动滑动、弯曲和整体游动 | B；真核纤毛不按细菌鞭毛的旋转马达工作 |
| U04 | 草履虫摄食与消化 | 口沟、食物泡形成、运输、消化与排出 | A，可复用已有器官层级 |
| U05 | 草履虫伸缩泡 | 改变外界渗透条件，观察收集和排水周期 | A；不把它等同于食物泡或动物肾脏 |
| U06 | 草履虫接合与核重组 | 并列两细胞，追踪小核事件和大核重建 | C；接合本身不是使细胞数立刻翻倍的繁殖 |
| V01 | 裂解周期 | 连接吸附、递送、表达/复制、装配、释放 | A，已有 T4 起始部分；宿主和感染后的资源变化需要新场景 |
| V02 | λ 噬菌体溶原与诱导 | 比较整合、随宿主遗传和切换到裂解 | B，明确新增 λ 示例；不能把 T4 示意直接改名用来展示溶原 |
| V03 | 衣壳装配与 DNA 包装 | 观察装配、包装马达与基因组进入衣壳 | B，选具体噬菌体；机制和先后关系不能泛化到所有病毒 |

这些候选是内容范围，不是已通过逐项文献审校的动画脚本。进入制作的每个模块都必须固定物种、细胞状态和证据来源，尤其是生活史、免疫及病毒专题。

## 建议实施顺序

| 批次 | 模块组合 | 为什么先做 | 可复用内容与主要新工作 |
| --- | --- | --- | --- |
| 1 | 翻译；启动子/因子；增强子；核小体可及性；lac 操纵子 | 补上 DNA→RNA→蛋白质，并把真核与细菌的调控区别讲清楚 | 复用 DNA、核糖体和转录播放器；新做因果干预与表达结果面板 |
| 2 | TAD/环挤出；RNA 加工；DNA 复制 | 在基础建立后理解空间调控、RNA 命运和遗传物质复制 | 新做动态染色质、接触矩阵、剪接和复制叉；每个独立验收 |
| 3 | ATP 合酶/呼吸链；膜运输；质壁分离；气孔开闭 | 引入能量、跨膜关系及植物特有的可操作现象 | 复用膜/线粒体/叶绿体；新增保卫细胞以及方向、守恒校验 |
| 4 | 有丝分裂与胞质分裂比较；细菌二分裂；酵母出芽；草履虫伸缩泡 | 让不同生物的行为差异清楚可见 | 新做拓扑变化和多细胞镜头；不能用简单缩放假装分裂 |
| 5 | 完整裂解周期、λ 溶原、接合、趋化和其余专门专题 | 扩展到细胞间相互作用与生活史 | 新宿主/菌种/细胞类型；复杂调控先选一个可靠实例 |

批次内逐个完成，不承诺一次铺满全部候选。TAD 可作为重点提前做设计，但应在启动子、增强子与可及性三课之后正式接入。

## 每个过程的统一体验

1. 从当前细胞/细胞器进入具体过程，保留返回原结构的路径。
2. 基础层先说明发生位置、参与者和输入输出；进阶层再显示分子名称与调控。
3. 演示模式可播放、暂停、逐步、拖动及慢放；变量改变后暂停或重置到明确定义的状态。
4. 对适合的机制提供一个小实验：改变一个条件，观察一个有意义的结果，并可恢复对照。
5. 三维、反应图、序列或曲线各司其职。无实验参数时只显示定性趋势，明确教学示意。
6. 时间压缩、粒子数量、比例和随机性有说明。粒子是分子还是浓度标记必须讲清楚。
7. 模块增多后保留具体过程名称：显示常用过程，加“更多过程”目录；按基因表达、能量、运输、分裂与信号筛选。不要把几十个过程直接堆成一条标签栏。

## 接入前验收

- 生物学：物种、位置、方向、膜两侧关系、关键中间态与适用条件正确；涉及研究模型时区分已知机制、选定假设与示意结果。
- 因果：干预改变的变量确实对应动画与说明；不是只改颜色/文案；无参数支持就不显示真实速率或准确表达倍数。
- 状态：任意拖动、反复切换、重播结果一致；随机场景固定种子；正常与扰动状态相互切换没有残留。
- 产品：中英文、相关结构、入口命名、手机宽度、键盘操作、加载失败恢复。真机需要接入设备后另测。
- 性能：各过程独立按需加载；同型资源复用；逐帧更新避免分配几何；只有当前场景运行。
