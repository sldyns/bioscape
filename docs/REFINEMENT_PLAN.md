# Cell Atlas 逐项精修计划

状态：第 01–13 项已完成本地验收；目标模式本轮工作完成。最后更新：2026-09-18。

## 原则与完成标准

- 按下表顺序推进，当前项达到验收标准后再进入下一项。不同时铺开多个细胞器。
- 每项依次完成：核对科学结构与示意边界 → 建模 → 交互与双语内容 → 实际浏览器验证 → 记录结果。
- 页面坚持浅色、留白、系统字体、少量必要控件；不加入探索分数、挑战、学习进度或装饰性面板。
- 结构应有形态依据，不能只把同一个球或颗粒换颜色。复杂度服务于理解，不能以增加随机颗粒替代有效细节。
- 分子级形态为教学示意，不声称原子级准确。跨层级单独缩放；重要省略与比例调整要在相关说明中可查。
- 验收包含：首次进入、实际可点击部件、子级目录、返回父级、完整/剖面/拆解的适用性、标签与遮挡、旋转缩放、中英文和窄屏。没有意义的控制不显示。
- 构建通过仅代表代码检查；视觉验证、科学核对与交互验证分别记录。未验证不得写成已完成。
