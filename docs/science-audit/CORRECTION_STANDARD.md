# Phase B correction and acceptance

Only start after explicit root release following full 84-model Phase A coverage. Own the assigned audited group plus any explicitly assigned original process. Do not alter another group, global renderer/catalog, thumbnails, existing audit evidence, or unrelated structure scenes. Keep Phase A immutable.

Fix every confirmed issue in your audit, including important P2 ambiguity; qualified passes do not need invented changes. Resolve unresolved evidence before selecting a representation. Prefer a conservative faithful model over ungrounded fine detail. A caption about simplification cannot excuse wrong molecular identity, strand handedness, membrane topology, reaction order, material duplication, or species assignment. Do not fix by hiding the whole process, removing the concept, or lowering visual quality.

Use experimentally derived structures already in the repository when applicable, retaining chain identities, gaps and one common assembly transform. Do not present a hollow membrane-like shell with arbitrary floating helices as a protein/RNA complex. Separate a real structural reference from a magnified reaction schematic if the literal molecular scale makes the educational event illegible; label that distinction in both languages. Molecular motions remain illustrations, not simulated atomic trajectories.

Explicitly maintain: molecular continuity; which end is covalently attached; topology through all intermediate frames; compartment separation except at drawn pores/fusion necks; time-ordered activation; no duplicated substrate/phosphate/ubiquitin; evidence-based organism scope. Interpret approximate shapes responsibly: nearest vertex distance is not distance to a triangle surface, and unrelated teaching marker counts are not necessarily stoichiometric counts. Verify the claimed failure, not just a convenient proxy.

Add a meaningful local scientific regression (science.test.mjs or equivalent in the owned group), grounded in the audit's invariant and actual geometry/state. It must fail if the original defect returns. Metadata-only assertions are insufficient for geometric defects. Test both branches and intermediate times; finite vertices, deterministic seeks and stable resource inventory remain required. Do not run full-workspace verification while other groups edit. Format only owned files. No browser automation; root will render and inspect.

Write docs/science-audit/resolutions/<group>.json:
{group, issues:[{issueId,status:"fixed|unresolved",changes,files:[],verification:[],limitations:[]}], unchangedModels:[], commands:[], sourcesAdded:[]}
Also concise <group>.md. Every original issueId must appear exactly once (shared-root fixes may address several ids). Record fixes factually; root reviews evidence and visual results before accepting. Report completion, modified files, command/results and anything still unresolved. Do not say that tests prove every scientific fact.
