# Signals 膜修复独立复核

复核人：p_signals。只读模型与测试；仅写本报告，未操作浏览器。范围：signals-04 凋亡同一染色质货物的膜包装，以及 signals-07 排核全过程的膜封闭、包含和真实分裂点。

**最终结论：指定膜修复通过独立几何复验，peer-signals-01 已闭环。** 首次复核确认两模型的质膜修复，并发现排核期间 DNA 穿核膜；作者随后将核膜、DNA/linker 和组蛋白芯纳入同一局部形变。以下保留首次缺陷证据及冻结修正版本的独立复验结果。此结论仍不替代浏览器外观验收或其余 signals 科学审计。

## 已通过：实际质膜与同一货物

每个模型检查 126 帧：0、.2、.4、.6、.7，加 .70–1 步长 .0025（.7 重复一次）。取实际膜 `drawRange` 内三角形，构建 BVH；将货物真实顶点变换到膜坐标，按三角面射线交点奇偶判定包含，并从实际相邻三角形恢复膜组件归属。没有使用 userData 的封闭/包含声明。

- **凋亡**：共检查 **13,827,240 个货物表面顶点**，包含五组预先存在的 cargo 下全部 DNA/组蛋白网格，不仅是对象中心。所有采样顶点都在膜内，且每份货物全部属于其中心所在的同一膜组件；对象身份全程保持。末态五份货物分别属于五个独立膜体，第六个膜体为母体残留。
- **排核质膜**：共检查 **53,550 个实际核表面顶点**，所有采样帧均被质膜包含；不是以核中心或解析球代替实际已变形的核网格。
- 每个采样帧检查实际三角网格边邻面数均为 2；未发现膜破口。`noStress` 与 `impaired` 末态各保持一个闭合膜体。

对每次组件分裂进行 14 轮二分，随后在上下界及两侧 1e-5 附近重查。以下是几何分裂进度区间，属于模型参数而非生物测量时间：

| 模型 | 组件变化 | 分裂区间 |
|---|---:|---|
| apoptosis | 1 → 2 | .92909271–.92909424 |
| apoptosis | 2 → 3 | .93107941–.93108093 |
| apoptosis | 3 → 4 | .93163483–.93163635 |
| apoptosis | 4 → 5 | .93613770–.93613922 |
| apoptosis | 5 → 6 | .93832733–.93832886 |
| differentiation | 1 → 2 | .86625397–.86625488 |

上述临界点前后均保持闭合边邻面计数。另做实际三角面对三角面相交测试：**500 对凋亡货物/质膜网格、4 对核膜/质膜网格均不相交**。这排除了只凭“组件数变化”就认可包装的做法，也补充了仅测试表面顶点可能漏掉三角形跨膜的局限。

## 首次复核发现：排核时 DNA 穿过正在腰缩的核膜（已修复）

定位：`src/processes/modules/signals/differentiationProcess.js:47` 的三组 `chromatinFiber` 保留原始局部坐标；`:213–226` 仅对 `nuclearSurface` 的 y/z 顶点应用 `1 − .22 sin(π extrude) exp(−x²/.16)`。核膜局部收窄时，DNA 没有同样收窄。

独立检查每帧全部 **64,836 个 nucleosomal-dna 表面顶点**，先验证其仍在质膜内，再对实际核膜三角面验证核内包含：

| 进度 | DNA 顶点位于核膜外 | 位于质膜外 |
|---:|---:|---:|
| 0 / .70 | 0 | 0 |
| .78 | 134 | 0 |
| .81 | 2,692 | 0 |
| .835 | 4,187 | 0 |
| .85 | 3,558 | 0 |
| .866254 | 2,089 | 0 |
| .89 | 134 | 0 |
| 1 | 0 | 0 |

p=.835 的外穿最大世界空间距离为 **.07393077**（最近三角面距离，不是最近顶点）。一个实际 DNA 顶点为 `[1.0606723, .4051664, .2437744]`；最近核膜表面点为 `[1.0534694, .3532335, .1916511]`。再次以 BVH 三角形相交直接确认：**6 条 DNA 网格中有 4 条与核膜相交**。这不是中心点误差、浮点阈值或端态正常就能排除的问题。

建议把核膜及其内容物放入同一局部形变，或选择能持续容纳真实染色质网格的核形变。修复应保留 DNA 连续性与组蛋白包绕关系。回归需同时检查 `DNA ⊂ 核膜 ⊂ 质膜`，特别是 .78–.89 和质膜分裂点两侧；不能只验证核膜被质膜包住。

## 作者修正后的独立复验：peer-signals-01 闭环

核膜和三组染色质的全部网格先转换到共同核内坐标，保存原始顶点，再应用相同的局部腰缩映射并回写各自局部坐标。实际读取到的代码不隐藏 DNA，不删除 linker/组蛋白，也不替换成新的示意货物。

在作者冻结版本上重新运行独立探针，未依赖作者的 `science.test.mjs` 结果。两种条件（competent/impaired）**各 39 帧**：0、.7、.76–.91 每 .005，以及原质膜分裂区间的五个临界采样和末态 1。包含明确要求的 .81、.835 和 .866254。

- **5,057,208 个 DNA 表面顶点**和 **262,080 个组蛋白芯表面顶点**全部满足 `染色质 ⊂ 实际核膜 ⊂ 实际质膜`；未发现穿核膜或穿质膜。
- **33,150 个实际核膜表面顶点**均被质膜包含。
- **2,886 对实际网格三角面检查**（染色质/核膜及核膜/质膜）全部不相交；这覆盖了首次复核曾出现四条 DNA 网格相交的 .835 帧。
- 染色质对象和几何 UUID 保持，全部被测 DNA/组蛋白网格保持可见。
- 功能完整条件的质膜在 `.86625397` 仍为一个闭合组件，在 `.86625488` 变为两个闭合组件；两侧及邻近点边邻面数均为 2。impaired 在同一组采样仍为单一闭合组件。修核内形变没有改变原质膜分裂点或异常分支。
