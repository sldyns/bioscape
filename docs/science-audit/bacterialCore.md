审计者：`p_bacterial_signals`，未参与 bacterialCore 编写。审计范围为 entries.js 的全部 4 个模型，均仅声明 `bacterium` root；覆盖全部阶段、8 个条件分支、输入输出、中文/英文教学文案，以及几何创建和 update 公式。已查看现有代表截图，并对阶段端点、中点和关键过渡采样；有限变换检查通过，但不作为科学正确性证据。未修改产品文件。

**结果：4 个 confirmed_issue；7 项问题（P1 × 5，P2 × 2），无 P0。** 完整证据、文件行号、来源支持范围、修法及验证不变量见 [bacterialCore.json](./bacterialCore.json)。

## bacterialExpression — confirmed_issue（high）

物种/范围：大肠杆菌，σ 因子依赖的转录起始和转录—翻译耦联。检查 `sigma=present/absent`。

- **bacterialCore-01 / P1：新生肽没有接到 50S 出口。** `bacterialExpression.js:221–232,379–395`：加载完成后，出口环中心与首个肽珠中心相距 0.361；肽珠半径仅 0.072，且没有连接线段。应从出口的世界坐标生成连续肽链；整个翻译阶段近端肽链须与出口连续，斜视时也成立。[新生链与核糖体出口结构：6I0Y](https://www.rcsb.org/structure/6I0Y)
- **bacterialCore-02 / P1：新生 RNA 的 3′ 端脱离 RNAP 活性位点。** `:173,296–321,363–378,420–421`：RNA 端与已建模的活性位点相距约 0.383；无内部连接或 RNA–模板短杂交区，3′ 标签又独立放在另一处。应以活性位点为真实 3′ 端，连续连接出口和游离 5′ 区，标签跟随实际端点。σ 缺失时仍须无转录产物。[Wang 等，2020，摘要及图 1](https://pubmed.ncbi.nlm.nih.gov/32820061/)、[耦联复合物结构 6VYW](https://www.rcsb.org/structure/6VYW)

已确认的正确关系：RNAP 沿模板 3′→5′ 前进，核糖体沿 mRNA 5′→3′ 移动；DNA 没有进入核糖体。rRNA 几何是单条 RNA 管线，不能仅凭局部弯曲判作双链 DNA。蛋白/rRNA 形状仍是非原子级抽象；截图 p=0.55 尚未覆盖后期完整翻译状态，以上缺陷由坐标和公式确认。

## bacterialDivision — confirmed_issue（high）

物种/范围：大肠杆菌慢生长单轮复制与分裂。检查 `septalSynthesis=active/blocked`；不把此时序外推为所有生长条件。

- **bacterialCore-03 / P1：未复制完的 DNA 分支被拆开，复制叉悬空。** `bacterialDivision.js:474–499`：整条亲本环左移，尚未闭合的姐妹弧右移，而叉采用第三套位移。p=0.37 时复制完成度约 94.5%，同一分支点的两份位置已相距约 1.59；未完成姐妹链有游离断端。应在复制期间保持共享叉的连通 θ 拓扑，允许已复制区域分离；完成后再成为两个闭环。验证两叉始终落在 DNA 分支点、无游离新生臂端，最终每个子细胞一个闭合染色体。[Nielsen 等，2007，活细胞复制/分离实验](https://journals.asm.org/doi/10.1128/jb.01212-07)
- **bacterialCore-04 / P2：FtsZ 与隔膜一起缩成点，缺少封闭前解聚。** `:501–535`：FtsZ 所有尺寸乘以 `1-constriction`，其可见窗口延续到膜已闭合之后；没有独立离开过程。应在膜颈仍开放时降低 FtsZ 占据或解聚，保留后期壁合成，避免蛋白本身缩成零厚度。需存在“膜颈开放、FtsZ 已明显离开”的非零时间段。[Söderström 等，2014，FRAP 与定位证据](https://pubmed.ncbi.nlm.nih.gov/24506818/)、[2024 分裂综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC11102604/)

已确认：FtsZ 位于胞质侧，细胞包膜层级和两子细胞输出基本合理；阻断隔膜合成不会正常完成分裂。问题集中在复制连通性和收尾时序。

## conjugation — confirmed_issue（high）

物种/范围：大肠杆菌自主 F 质粒接合，非 Hfr 染色体转移。检查 `oriT=intact/blocked`。

- **bacterialCore-05 / P1：转移 T 链在不同阶段被重复或断开。** `conjugation.js:124–141,264–271,315–334`：p=0.47 时供体 T 环尚完全闭合，但已有同色跨细胞链；中途供体剩余弧的端点变化，转移桥起点却固定于原 oriT。p=0.64 时两端 x 坐标相差 0.98；p=0.785 时受体环已闭合，桥仍存在。应由一条有物质顺序的连续 T 链描述切口、输出、5′ TraI 前导端和尾端到达，全部进入受体后再闭环。验证转移期间是连续、非分叉的线性 T 链，闭环时无跨细胞链；oriT 阻断时无切口转移。[Couturier 等，2023，F 接合实时观察](https://www.nature.com/articles/s41467-023-35978-3)

已确认：供受体分别复制补链、转移链 5′ 前导、双方染色体保留、受体获得供体能力需基因表达。未表示配子融合或个体数增加，未混同有性繁殖。受体补链与输入的相对时序在所引实验中仍有限制，本审计不要求强行改为严格不重叠步骤。T4SS 非原子级结构不作精确化学计量断言。

## transformation — confirmed_issue（high）

物种/范围：枯草芽孢杆菌天然转化；单层胞质膜、厚肽聚糖、同源重组。检查 `homology=matched/absent`。

- **bacterialCore-06 / P1：同源链尚未接触，受体整段原链就被移除。** `transformation.js:271,299–308,348–366`：`pair>0.01` 即同时隐藏染色体整段弧、显示被置换链；p=0.68 时 pair 仅 0.028，输入端距靶位约 1.52，却已挖掉整段原链。应先完成接近/同源配对，再由局部 D-loop 和交换前沿推进。验证任何被置换位置都已有输入链接触配对；接触前受体完整，无同源性分支不移除原链，最终异源双链两骨架连续。[Kaufenstein 等，2011，摄取及 RecA 链侵入机制](https://journals.asm.org/doi/10.1128/jb.01128-10)
- **bacterialCore-07 / P2：膜结合 ComEA 漂浮在膜外。** `:112–119,199–214`：ComEA 只有两叶和短管，没有跨膜段或系链；其最靠膜几何约 x=-1.98，所在半径的膜帽约 x=-1.77。应补出接入单层胞质膜的锚定段和膜外 DNA 结合域，或明确表示有系链的局部结构。验证锚只跨这层膜、DNA 结合域朝外，两个条件均成立。[ComEA 膜结合定位的实验来源](https://journals.asm.org/doi/10.1128/jb.01128-10)

已确认：胞外双链 DNA 经膜时仅一股输入，另一股被降解；DprA/SSB/RecA 与胞质步骤的总体次序合理，RecA 螺旋是包裹单链的蛋白而非双链 DNA。无同源性时仍可摄取但不整合；最终整合表示输入链与保留互补链形成异源双链，后续复制不在本示范内。
