# Division 修正闭环

**division-01 至 division-06 均已修正。** Phase A 原报告未改；只改 division 模型、局部辅助函数和新增本组几何回归，未操作浏览器。

- **01 插极微管**：拆成方向相反、末端独立的两组微管，在中部交叠；分裂时交叠区缩短。测试真实 instance 两端，禁止单根跨两极。
- **02 / 06 动粒接触**：用射线与真实外动粒三角面相交取得目标，再应用染色体变换。测试最近三角面距离，不用最近顶点代替。正常八个端点接触，异常仍只有七个；I 同向、II 双向保持。
- **03 小鼠形态**：两对常染色体均采用端着丝粒几何；实际短臂不到总臂长 3%，不再是约 43%。双语范围同步更新。
- **04 交换位点**：两条非姐妹染色单体在共同 .69L 位点形成连续交叉路径，祖源材质分界和交叉标记在同一位置。联会横档连接真实同源轴。回归直接比较交换双方的几何接缝。
- **05 胞质桥**：改为一个连续双层膜面，胞质分裂形成两叶、四叶并保留三个有腔膜颈；无子细胞封口膜，也无实心连接棒。测试内腔贯通、双层膜壁存在、桥口无裂隙，唯一开放边界是前侧观察剖面。

染色体总数、同源及姐妹分配、两次分裂间无复制、有丝检查点实际阻滞均保留。`science.test.mjs` 与 `division.smoke.mjs` 通过；本组格式检查通过。Smoke 包含两模型局部 esbuild、有限坐标/法线/范围、资源稳定与乱序跳转确定性。当前目录不是 Git 仓库，未声称完成 git diff 检查。

可视验收由 root 进行。新的膜面是有限采样示意，初测变化中的膜面约 33 ms/update，稳定膜面阶段约 6 ms/update（本机无渲染采样）；该数据不代表浏览器帧率。其余尺度、时间及交叉运动仍为教学示意，测试不构成全部生物学事实的证明。
