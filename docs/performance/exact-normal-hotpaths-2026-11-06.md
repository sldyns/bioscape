# 曲面法线更新：配对测量与验证范围

本次将三个已测热点中的 `computeVertexNormals()` 调用改为复用项目现有的 `computeIndexedFloat32VertexNormals()`：λ 溶原细胞分裂的包膜、细菌分裂包膜，以及纤毛的变形曲面。该实现已用于分裂和膜形变模型，保留 Three.js 的三角形顺序、每次 Float32 累加写入和归一化。输入格式不受支持或法线尚未创建时仍调用 Three.js。

基线为 [v1.1.0 / 2a6a49f2](https://github.com/sldyns/bioscape/tree/2a6a49f2f998d6e2563230b9853441e77f20146e)。没有改变拓扑、顶点数量、材质、标签、抗锯齿、阴影、环境、输出分辨率或编码设置。

## 模型正确性和画面

从实际注册表派生 114 个根模型上下文、235 个根模型/条件组合和 1,384 个章节条件。每个组合检查 0、0.1、0.4、1、章节起点及其前后 0.001、章节中点，共 5,990 个正向状态；在同一模型中按相反条件和进度顺序再次检查，合计 11,980 次。

检查包括完整几何属性、法线、实例矩阵、可见状态、绘制范围、材质数值、实例数量、活动标注文字与坐标、可见边界、对象/几何资源身份，以及观察到的资源恰好释放一次。活动标注和边界的返回差异均为零。隐藏标注的缓存坐标不用于绘制，仍检查有限性，保留原始值，但不将其历史差异判为可见画面变化。初始验证器的这一误判和原始记录保留。

候选的全部 5,990 个状态与冻结基线一致。已有法线单元检查的 20 组变形和 5 组兼容回退通过。通用过程测试也补充了完整条件/章节矩阵，以后运行 `npm run check` 会检查这些根模型、条件和跳转路径。

浏览器对照使用六种条件，每种在 0、0.199、0.37、0.499、0.59、0.649、0.79、1 八个进度捕获 1920×1080、含标签的画面。48 组逐像素对照的变化通道数均为零，绘制设置一致。代表性的六对 PNG 文件字节相同；五张不同的原始画面已逐张检查，两个 λ 条件在所保存进度的画面相同，复用该原图进行复核。

## 自然 DPR2 的浏览器配对测量

使用现有 Chrome 的自然窗口：1680×705 CSS 像素、DPR 2、浏览器缩放 1。场景画布为 1240×452 CSS 像素，实际 2480×904；两个版本使用相同的 88 像素标注目录区域。没有设置视口或 DPR 覆盖，也没有改变浏览器启动配置。

每种条件按 A-B-B-A 顺序执行，每个窗口先预热 80 帧，再按完整 0→1 时间线记录 240 次实际 `ProcessScene` 回调。六种条件共 24 个窗口、5,760 次回调。记录模型更新、完整渲染回调和 RAF 间隔；热路径只增加三个时间戳及固定数组写入，不序列化、不更新验收界面、不读取可访问性树。每个窗口前后核对焦点、可见性、画布和窗口尺寸，均无变化。

下表采用较保守的比较：两轮基线中较快的 P95，对比两轮候选中较慢的 P95。

| 过程与条件 | 基线模型更新 P95 | 候选模型更新 P95 | 耗时变化 |
| --- | ---: | ---: | ---: |
| λ 溶原周期：诱导 | 11.9 ms | 4.1 ms | 减少约 65.5% |
| λ 溶原周期：维持 | 11.9 ms | 4.3 ms | 减少约 63.9% |
| 细菌分裂：正常隔膜合成 | 4.0 ms | 2.2 ms | 减少约 45.0% |
| 细菌分裂：隔膜合成受阻 | 3.8 ms | 2.1 ms | 减少约 44.7% |
| 纤毛运动：有 ATP | 6.4 ms | 2.3 ms | 减少约 64.1% |
| 纤毛运动：无 ATP | 0.4 ms | 0.5 ms | 增加 0.1 ms，在预设空闲噪声容差内 |

预先规定活动热点的模型更新 P95 至少改善 20%；空闲条件允许 0.3 ms 绝对噪声。完整回调与 RAF 的 P95 不得恶化超过 `max(1.5 ms, 基线的 10%)`。所有窗口通过该规则；没有为得到通过结果重放某个测量窗口。主绘图路径仍使用相同的抗锯齿、阴影、环境和绘制设置，共用一个渲染器；结束后该资源恰好释放一次。控制台错误和警告均为零。

## 边界与发布要求

上述数值是这些模型、条件、固定场景布局和本机浏览器中的 CPU/回调测量。程序化时间线推进不等于持续鼠标输入；RAF 不等于物理呈现或刷新率。它不证明全站普遍提速、所有设备表现、235 个组合在每个章节的浏览器画面验收、正式持续输入 DPR2 验收，或物理稳定 60 FPS。

版本发布仍需完整 `npm run check`、同一提交的 Verify 和 Pages 成功，以及实际线上资源和相关操作复核。原有导出管线保留；共享渲染和 15 秒导出的上一轮记录见[共享渲染专项验证](shared-renderer-2026-11-06.md)。冻结基线、初始验证器记录、配对原图和原始测量记录均保留。
