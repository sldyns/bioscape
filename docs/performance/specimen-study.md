# 标本与过程的观察方式

## 结构模型

目录有 9 个根标本，沿各层入口去重后共有 182 个结构模型。模型页可以对照当前视角、横转 90°、背面和该模型的补充斜视。四张图保留当前的旋转中心、缩放、布光与结构模式。点击图像会把主模型转到对应方向。定位菜单使用当前模式可见的部位和模型已有的地标，选中后相机移向其三维坐标。

第四个视角按每个模型的实际网格投影选择。候选角度考虑屏幕上能新看到的表面、轮廓、地标的分离以及细长结构的投影跨度。每个方向按当前网格以及主视窗和图版各自的宽高比重新取景，保留用户主动放大的比例。总览取景另对圆形标本做了缩放校正，避免包围盒的空角挤占细胞内部细节的显示面积。182 个选择保存在 [specimenAngles.json](../../src/scene/specimenAngles.json)。

## 过程模型

84 个过程共用 503 个编写的阶段。按照每个过程能从哪些根标本打开来计，共有 114 个有效入口、679 个带上下文的阶段。每张图采用页面当前的模型实例、参数和取景。默认参数下，对每段内七个时刻的活跃标注、坐标与可见网格做比较，选取接近该段典型形态的时刻。最后一张取动画终点。用户改变参数后，各段在当前条件的中点重新渲染，末张仍取终点。阻滞分支用观察时刻标识这些图，保留模型对所选条件的实际响应。

图版打开时才会绘制，以原场景的 WebGL 渲染器输出 576 × 360 像素图像，关闭时释放离屏渲染资源。每张图可以跳回相应的可操作姿态。“播放本步”在下一步切换前停住。时间表示演示播放时间。在标注栏点选编号后，圆环会跟随对应的三维点，部位失活时解除选择。

## 局部重建

| 标本或过程 | 可以直接观察的变化 |
| --- | --- |
| 成熟红细胞 | 打开时显示双凹盘。膜近景可跟随血影蛋白到锚蛋白，血红蛋白近景可辨螺旋和铁配位。血红蛋白的坐标依据人脱氧血红蛋白记录。[PDB 2HHB](https://www.rcsb.org/structure/2HHB) |
| 神经元与骨骼肌 | 轴突颈与终扣的剖面相连，切到的突触小泡可见囊腔。肌浆网的两端终池和 40 个开窗属于同一个闭合网面。整肌与局部肌原纤维显示对应的 Z 盘截面。 |
| 线粒体 | 裁切边缘显示一片连续内膜形成的两条嵴腔。嵴顶成对的合酶作为尺度线索。ATP 合酶的膜片、转子、中央轴和外围支架可以从不同方向辨认。[哺乳动物线粒体的冷冻电镜断层研究](https://pubmed.ncbi.nlm.nih.gov/18323778/) |
| 植物水分 | 完整水分子能穿过水通道，气孔闭合时水示踪向外移动，质壁分离后液泡的状态与所选条件一致。水从根毛经皮层进入木质部的路径避开导管壁。 |
| 酵母 | 出芽可见分隔位置和留在母细胞一侧的芽痕。配对过程中的分泌囊泡绕过亲本细胞核。产孢时四个前孢子膜的内外表面在开放边缘连续反折。 |
| 细胞分裂和菌丝 | 有丝分裂的星状微管朝实际细胞皮层延伸。减数分裂的膜计算复用已求得的交点和梯度。菌丝顶端的示踪囊泡在接触前保留可见膜间隙。 |

## 复核

- `node tests/study-plates.mjs` 对照公开目录、双语阶段、条件分支和阶段终点，完整覆盖 182 个结构和 114 个过程入口。
- `node scripts/specimen-angles/generate.cjs --out /tmp/bioscape-angles` 从实际几何按原图版大小重新计算 182 个补充视角。工具使用本地 Chromium 和 Playwright，可通过 `CHROME_BIN` 和 `PLAYWRIGHT_MODULE` 指定已安装的位置。
- `node --expose-gc scripts/generate-study-moments.cjs --check` 从真实工厂重新生成并核对阶段表。追加 `--report /tmp/bioscape-stage-report.json` 可以保留逐入口采样记录。
- `npm run check` 依次执行格式、模型与界面回归、生产构建和成品资源检查。新增科学回归检查水通道与导管间距、肌浆网拓扑、前孢子膜边缘、染色体分裂中的星状微管以及线粒体膜与支架连接。几何测试使用模型单位。
