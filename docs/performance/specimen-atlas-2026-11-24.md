# BioScape 标本图鉴改版

本次本地改版以 v1.1.6 为基线。9 类模型、182 个结构、84 个过程继续沿用现有模型和双语讲解。改动覆盖了浏览目录、进入标本、操作模型、播放过程和导出影像的整条路径。

## 浏览与交互

首页直接展示现有的 1400 像素透明标本图。切换动物细胞、植物细胞或神经元时，封面、名称和探索入口一起更新。点击「交互预览」才加载三维场景。减少动态效果偏好生效时，访客仍可以手动操作模型。

标本、生命过程和探索工具各有独立入口。过程搜索索引在载入目录时建立一次。桌面和窄屏使用同一套目录数据、语言选择和深链接。

## 光照与材质

结构与过程使用同一套环境反射和直接照明。渲染器首次使用时将三个面光源的辐亮度预滤到环境贴图，后续画面重复采样。柔光让正面的遮挡区域保留层次，侧光降低环境填充并改变主光方向，让膜上的凸起和折叠更明显。切换布光时保留画布、机位、过程进度和标签状态。对比工作区的两个模型同时应用所选照明。

细胞膜保留原有构型、染色和可选部件。脂质头部有较集中的高光，尾部呈漫反射，蛋白与糖链采用各自的粗糙度。这些参数用于帮助读图。影像工作台从当前场景捕获图像，可独立选择背景和分辨率。

## 绘制与播放

动物细胞总览将三份刚性重复的线粒体按表面做实例化绘制，保留原有网格、阴影、剖切和爆炸分组。点击检测按实例使用同一个几何加速结构。进入单个线粒体时仍可独立探索嵴、基质及其他下级结构。

过程播放在同一次动画帧回调内更新姿态、标注和画面。场景离开可视范围后跳过绘制和标注布局，回到画面时按播放进度恢复。再次进入同一过程及参数组合时复用已验证的六个取景边界值，各次访问分别持有自己的模型和渲染资源。

## 实测方法

在同一台 Apple M1 上通过 Chrome 157 和 ANGLE Metal 运行本地生产构建。桌面视窗为 1440 × 900，设备像素比为 2。每个冷启动用独立浏览器上下文和禁用的 HTTP 缓存，取三轮中位数。模型就绪包括几何和着色器准备。加载量统计首页标题出现后两秒内完成的资源，服务器提供未压缩内容。

| 指标 | v1.1.6 | 本地改版 |
| --- | ---: | ---: |
| 首页自动加载的 JavaScript | 1,623,546 B，9 个请求 | 444,636 B，2 个请求 |
| 首页两秒内完成的子资源合计 | 3,109,580 B | 1,933,660 B |
| 首页最大内容绘制 | 156 ms | 120 ms |
| 从首页点击到动物细胞就绪 | 2,326 ms | 2,148 ms |
| 直接进入动物细胞至就绪 | 2,398 ms | 2,229 ms |
| 直接进入细胞膜至就绪 | 569 ms | 563 ms |
| 直接进入分泌过程至就绪 | 665 ms | 629 ms |
| 动物细胞剖面每帧绘制调用 | 152 | 118 |
| 分泌过程播放四秒的 rAF 间隔 P95 | 16.8 ms | 16.7 ms |

另做五对交错拖动，每次向动物细胞或细胞膜发送 60 次真实鼠标移动。动物细胞每轮 P95 的中位数均为 33.4 ms。旧版五轮中有 6 个间隔超过 50 ms，新版五轮为 0 个。合并样本的 P99 从 50.1 ms 降至 33.4 ms。细胞膜五对测试的 P95 逐对相同，为 16.7–16.8 ms。首页点击后出现结构页面外壳的中位数从 308.6 ms 变为 311.8 ms，完整模型更早可用。

动物细胞绘制缓冲区保持 1659 × 1047，细胞膜保持 1659 × 1033。相机、几何、抗锯齿、像素比上限和 2048 像素结构阴影图均按同一设置核对。rAF 记录浏览器回调的间隔，物理屏幕呈现时间需要单独测量。

## 交互与成品

- 英文首页选择植物细胞后，主按钮进入对应的英文模型。过程搜索能找到分泌过程。检查了 320、390、768、1440 像素四种视窗的首页宽度和标本控件间距。
- 在动物细胞与植物细胞的对比视图中切换布光，两块画布均重新绘制并保持各自机位。细胞膜的柔光、侧光截图来自同一画布和同一机位。
- 主动使膜模型的 WebGL 上下文丢失并恢复后，原有侧光和机位恢复，每帧绘制调用数仍为 14。分泌过程移出屏幕后，连续 850 ms 的观察中 WebGL 绘制调用计数保持不变，播放进度继续前进。重新滚入视窗后恢复绘制。
- 影像工作台实际导出了 1920 × 1080 透明 PNG，四角透明，标本和标注有非透明像素。分泌过程的六秒 1920 × 1080 MP4 已重新解码，读取时长并比较了不同时间的画面。
- 标准生产构建包含 388 个文件，合计 38,110,406 字节。站点的 84 个过程、9 个首页标本、3 个动态预览和子目录资源路径均通过发布检查。
