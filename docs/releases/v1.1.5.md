# BioScape v1.1.5

发布日期：2026-11-09（Asia/Shanghai）

[在线体验](https://sldyns.github.io/bioscape/) · [源码与正式版本](https://github.com/sldyns/bioscape/releases/tag/v1.1.5) · [更新日志](../../CHANGELOG.md)

植物细胞板接近亲本质膜时，狭窄的真实间隙曾落在两个采样点之间，导致画面提前连通。现在保留全部原采样点，并在连接区间加入连续变化的采样平面；囊泡与细胞板之间的细小间隙也纳入检查。原场函数、过程时序、其他结构、材质、相机和 GPU 顶点缓冲容量保持不变。

专项验证覆盖 1,142 个前后拖动状态、12,564 次间隙检查和 12 个拓扑状态。185,800 个新网格采样值与原场函数一致；菌丝两种条件及其他结构的状态检查通过。原生浏览器中，100 组原有双语全高清画面逐像素一致，另检查 64 组连接阶段画面，其中 40 组为预期的膜间隙修正。最终连接状态与原版一致。

真实应用完成双语切换、连接阶段正反向拖动、实际播放及关联结构往返。15 秒 1920×1080 全程视频在活动取消后重试成功，成片播放到结尾，下载文件具有完整的 450 帧时间戳；随后 PNG 导出成功，进度和视角恢复正常，渲染及编码资源全部释放。

[问题、方法和验证边界](../science/plant-junction-sampling-2026-11-09.md)。归一化过程进度和模型坐标用于确定性验证，不能解释为实验时间、真实长度或分子融合动力学。Node 计算开销检查通过预设预算；本次不新增提速或物理帧率结论。

版本、引用信息、中英文 README、更新日志、网站和 GitHub Release 同步维护。原有 Gal80 标注清理、媒体、科学来源及历史验收材料继续保留。发布附件提供实际网站产物、验证摘要和 SHA-256。
