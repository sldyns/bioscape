# BioScape v1.1.0

2026-11-06 · [在线体验 / Website](https://sldyns.github.io/bioscape/) · [GitHub Release](https://github.com/sldyns/bioscape/releases/tag/v1.1.0)

## 本次更新

浏览结构和生物学过程时，场景切换可复用同一对渲染器和环境资源，减少重复初始化。每次进入都恢复场景自己的绘制状态；比较视图使用独立画布。离开工作区、上下文丢失或资源失效时，资源会退役并按需重建。

共享层保留 v1.0.1 的异步画面读取和最多两帧准备机制。取消或关闭时释放未完成任务，重新进入时恢复所有者状态。输出分辨率、模型几何、抗锯齿、阴影、颜色、标签、30 fps 和原码率保持原样。

## 验证

- 九类结构与六个过程上下文的 60 组全高清画面逐像素一致；异步等待失效的兼容路径另有 60 组一致对照。
- 实际入口、结构/过程切换、比较返回，以及资源退役后重新进入通过回归。
- 蛋白质分泌的取消、关闭、重开及完整导出通过；它和 DNA 复制的两条 15 秒 1080p 视频均已播放和下载，分别为 450 帧、30 fps，编码时间戳无超过 100 ms 的间隔。
- 导出期间暂停工作台背景模糊合成，避免读回及编码收尾卡住；完成后恢复，成片画质设置保持原样。

具体结果、15 秒 MP4 信息和适用范围见[专项验收记录](../performance/shared-renderer-2026-11-06.md)。发布对应的 Verify 与 Pages 必须同时成功，网站资源须与验收构建一致。实际导出样例和 SHA-256 随 GitHub Release 提供。

这些检查验证共享资源、入口和导出组合，不替代所有场景的科学审查、所有设备 GPU 或物理 60 FPS 验收。历史失败与旧基线保留。

## English

Structure and process views share an idle renderer/environment pair, restore their own drawing settings and rebuild lost contexts. Comparison retains independent canvases. Scene re-entry and asynchronous capture keep their ownership and cancellation guarantees, without reducing output quality.

See the linked acceptance record for exact image comparisons, entry checks and full fifteen-second exports. Source, version metadata, documentation, CI, Pages, tag and release assets are published together.
