# BioScape v1.0.1

2026-11-05 · [在线体验 / Website](https://sldyns.github.io/bioscape/) · [GitHub Release](https://github.com/sldyns/bioscape/releases/tag/v1.0.1) · [更新日志 / Changelog](../../CHANGELOG.md)

## 本次更新

视频导出改用异步画面读取，最多同时准备两帧，随后按原顺序合成和编码。导出保留原分辨率、模型细节、抗锯齿、阴影、标签、教学说明、30 fps 和原码率。取消或出错时释放待处理画面与读取资源，保留同步及浏览器兼容回退。

匹配的本机测试中，6 秒 1080p 蛋白质分泌视频平均生成时间为 **3.99 → 2.55 秒，耗时减少约 36%**。这是该配置的测试结果；[测量方法](../performance/video-export-2026-11-05.md)列出四次运行、12 组画面对照和适用范围。

版本包含此前已合入的场景细节、视角恢复、渲染器及 Worker 生命周期、过程连续性与导出响应改进。九类模型、结构浏览、84 个生命过程、双模型比较、中英文界面、图片和视频工作台均包含在同一源码版本和网站构建中。

## 使用与获取

直接打开网站即可使用。进入一个结构或过程，打开“影像工作台”，选择画幅、长边分辨率、标签和标题；视频时长可选 6、10 或 15 秒。生成时保持页面可见，完成后播放检查并下载。

GitHub Release 提供源码标签、一个实际线上导出的 6 秒 1080p MP4 和对应 SHA-256 校验和。样例用于验证真实文件输出，不是所有场景的性能承诺。运行源码的方法见 [README](../../README.zh-CN.md)，维护发布的方法见[发布指南](../RELEASING.md)。

- 完整 npm run check：格式、模型与科学回归、生产构建、385 项发布文件及项目子路径检查。
- 导出专项：152 项定向检查；横屏、竖屏、细胞拆解合计 12 组逐像素对照；取消、重试及播放检查。
- 上线检查：新增、变更和关键资源共 29 项与已验收构建逐字节匹配，公共入口一致；实际线上生成、播放和下载 MP4，确认 180 帧、6 秒和编码时间戳。
- 版本和发布完成状态，以此标签对应提交的 [Verify](https://github.com/sldyns/bioscape/actions/workflows/ci.yml)、[Pages](https://github.com/sldyns/bioscape/actions/workflows/pages.yml) 成功记录以及 GitHub Release 为准。

逐像素对照属于抽样保真证据，编码时间戳属于成片证据；均不替代所有场景、真实手机 GPU 或物理 60 FPS 的验收。历史科学审查和未覆盖范围继续保留，不随版本发布改写。

## English

This patch accelerates full-resolution video generation with at most two independently prepared frames, preserving output order, visual settings and browser fallbacks. Pending work is released on cancellation or failure.

A matched local six-second 1080p test reduced mean generation time from 3.99 to 2.55 seconds, about 36%. Twelve sampled render pairs were pixel-identical. The release also includes the previously merged scene, view-restoration, renderer/worker lifecycle and biological continuity refinements.

Use the live website, or obtain the source and verified MP4 example from the GitHub release. Full verification, production asset checks and actual online export evidence are recorded separately from scientific and physical-FPS acceptance limits.
