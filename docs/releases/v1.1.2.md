# BioScape v1.1.2

2026-11-07 · [在线体验 / Website](https://sldyns.github.io/bioscape/) · [GitHub Release](https://github.com/sldyns/bioscape/releases/tag/v1.1.2)

## 本次更新

让模型和控件直接表达操作方式，减少常驻使用说明。

- 结构页删除“从整体，到内部”等导航教学、重复的进入/返回提示和泛化的“教学范例”说明，保留原有生物学内容。
- 过程目录移除整栏教学文案，由卡片区使用空出的空间。过程页的多层近义标题合并为“相关结构”，精简重复的旋转、返回及空状态提示。
- 对比页删除重复控件说明，保留简短的比例信息；影像工作台只保留生成期间保持页面可见的正常提示。
- 中英文同步，保留具体模型范围、参考来源、控件无障碍名称和必要的状态及错误反馈。

几何、材质、阴影、抗锯齿、共享渲染和原分辨率导出实现保持不变。

## 验证与发布

本地界面复核覆盖结构与过程切换、章节前进、工作台打开/切换/关闭、模型对比与交换、语言切换，以及窄屏目录。完整发布同时核对同一提交的 `npm run check`、Verify、Pages、公开网站文件和附件校验和。

本次清理不产生新的性能测量结论。此前版本的测量、成片和验收证据保留在各自版本记录中。

## English

Structure exploration, biological processes, comparison and Studio now use less instructional copy. Persistent navigation tutorials and repeated reminders have been removed, the process directory gives the available space to its cards, and related-structure headings have been consolidated. Chinese and English retain biological context, references, accessible control names and essential status/error feedback.

Geometry, materials, shadows, antialiasing, shared rendering and full-resolution export are unchanged. Local UI checks cover navigation, chapter changes, Studio controls, comparison swaps, language switching and the narrow directory layout. Publication verifies the full check, Verify and Pages at the same commit, followed by public-file and attachment checksums. This release makes no new performance claim; previous evidence remains with its original release.
