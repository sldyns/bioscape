# 按生物类型分类的高价值过程候选表

2026-09-19。供 Cell Atlas 后续逐项实施使用。涵盖适合当前产品扩展的主要高价值主题，不声称穷尽所有生物学过程；所有未明确列为现有功能的条目均为规划。

共有原理在不同表中重复列出，制作时应复用基础组件，并按物种、细胞类型和区室独立校正。一个复合条目可拆成多节，不要求挤进同一段动画。

当前已存在：真核 Pol II 转录、经典可溶性蛋白分泌、光合作用概览、T4 侵染起始。现有真菌模型是出芽酵母示例；专门细胞/组织/菌种需要新增相应模型。

## 动物细胞

| 过程 | 展示重点与适用范围 |
| --- | --- |
| DNA 复制 | 复制叉、前导链/后随链、冈崎片段与校对 |
| DNA 损伤修复 | 选择错配、损伤或双链断裂，比较相应修复路径 |
| 转录与启动子调控 | 启动子识别、转录因子结合、Pol II 起始与延伸 |
| 增强子—启动子调控 | 远距离调控、因子组合、正常与元件缺失对照 |
| 染色质可及性与表观调控 | 核小体重塑、DNA 甲基化和组蛋白修饰的具体案例 |
| TAD 与染色质环挤出 | cohesin、CTCF 方向、边界扰动、三维构象与接触矩阵 |
| RNA 加工与可变剪接 | 加帽、剪接、3′ 端加工及不同转录本 |
| 核质运输 | mRNP 输出、蛋白核定位与核孔选择性运输 |
| 翻译与蛋白质折叠 | 密码子、tRNA、A/P/E 位点、肽链与伴侣蛋白 |
| RNA 与蛋白质降解 | miRNA、RNA 降解及泛素—蛋白酶体，拆成独立子课 |
| 蛋白质分泌与膜蛋白定位 | ER→Golgi→细胞膜，比较腔内货物与膜蛋白朝向 |
| 胞吞、内体分选与回收 | 受体介导摄取、回收或送往溶酶体 |
| 自噬与溶酶体降解 | 包裹货物、融合、分解与组分回收 |
| 细胞呼吸与 ATP 合成 | 糖酵解、三羧酸循环、呼吸链、质子驱动力与 ATP 合酶 |
| 跨膜运输与渗透 | 扩散、离子通道、Na⁺/K⁺ 泵、耦联运输和体积变化 |
| 细胞骨架与马达运输 | 微管动态、马达步进、囊泡运输与细胞迁移 |
| 有丝分裂与胞质分裂 | 染色体凝缩、纺锤体连接、分离与收缩环 |
| 减数分裂与重组 | 生殖细胞中的配对、交换与两次分裂 |
| 细胞周期检查点与凋亡 | 条件不满足时暂停；选择动物凋亡实例 |
| 信号转导与分化 | GPCR/RTK 各选实例，连接外界信号、基因表达和细胞行为 |
| 动作电位与突触传递 | 新增神经元：通道、电压曲线、递质释放与回收 |
| 肌肉收缩 | 新增肌细胞：Ca²⁺、肌动蛋白—肌球蛋白与肌节变化 |
| 免疫细胞的识别与应答 | 新增指定免疫细胞：吞噬、抗原呈递或杀伤，分开制作 |

## 植物细胞

| 过程 | 展示重点与适用范围 |
| --- | --- |
| 光反应 | PSII/PSI、电子传递、水氧化、H⁺ 梯度、ATP 与 NADPH |
| 卡尔文循环 | CO₂ 固定、G3P 输出与 RuBP 再生 |
| 细胞呼吸与 ATP 合成 | 植物也有线粒体呼吸，与光合作用分开追踪 |
| 质壁分离与复原 | 外液条件、液泡体积、原生质体和细胞壁关系 |
| 气孔开闭 | 新增保卫细胞：光/ABA、离子、水、膨压与孔径 |
| 主动运输与液泡稳态 | 质膜 H⁺ 泵、共转运、液泡膜运输与离子储存 |
| DNA 复制、修复与核内转录 | 复用真核基本机制，使用植物核内语境 |
| 启动子、增强子与植物调控因子 | 选择植物基因案例，不复制哺乳动物的调控元件 |
| 染色质调控与 RNA 沉默 | 核小体、植物甲基化、siRNA/RdDM 分层展示 |
| 植物染色体三维组织 | 指定拟南芥或水稻，展示本物种局部结构域和联系 |
| RNA 加工与翻译 | 核内加工、核输出、细胞质翻译；与细胞器版本区分 |
| 细胞器蛋白导入 | 核编码蛋白导入叶绿体或线粒体，比较定位信号和转运 |
| 有丝分裂与细胞板形成 | 纺锤体、成膜体、囊泡融合和新细胞壁 |
| 细胞壁合成与伸长 | 纤维素合成、微纤丝排列、壁松弛与膨压 |
| 胞间连丝运输 | 相邻细胞间物质与信号交流及通透性调节 |
| 生长素信号与向性 | 感知、调控、极性运输与组织差异生长 |
| 叶绿体移动 | 具体细胞中不同光照条件下的位置变化 |
| 光呼吸 | 叶绿体—过氧化物酶体—线粒体的代谢协作 |
| C₃/C₄/CAM 比较 | 碳浓缩的空间或时间组织，需专门组织/昼夜场景 |
| 水与同化物运输 | 根吸水、木质部、韧皮部源—库关系，需组织尺度 |
| 植物防御与逆境响应 | 选一种病原信号或干旱情景，连接感知、表达与响应 |
| 减数分裂与双受精 | 新增被子植物生殖场景，展示花粉管与两次配子融合 |

## 细菌

| 过程 | 展示重点与适用范围 |
| --- | --- |
| DNA 复制、分配与二分裂 | 拟核复制、分离、FtsZ 与隔膜形成 |
| 细菌转录与翻译耦联 | σ 因子、RNA 聚合酶、70S 核糖体及正在形成的 RNA |
| lac 操纵子 | 乳糖/葡萄糖两种条件，LacI 与 CAP–cAMP 调控 |
| trp 操纵子与衰减 | 色氨酸条件、阻遏、翻译状态与 RNA 二级结构 |
| 两组分信号系统 | 环境刺激、组氨酸激酶和响应调节蛋白 |
| 鞭毛运动与趋化 | 马达驱动、游动/转向概率与营养梯度 |
| 细胞膜运输与能量转换 | 膜上呼吸链、ATP 合酶、转运蛋白；无虚构线粒体 |
| 糖代谢与发酵 | 选择具体菌种，比较不同电子受体和代谢终点 |
| 肽聚糖合成与细胞包被生长 | 前体运输、聚合、交联与分裂部位的新壁形成 |
| 接合与质粒转移 | 指定供体、受体、接合系统和 DNA 转移/补链 |
| 自然转化 | 具感受态的细菌摄取环境 DNA |

| 生物膜形成 | 附着、胞外基质、空间组织与分散 |

## 实施优先级与科学边界

- 第一条主线：翻译 → 启动子/转录因子 → 增强子 → 染色质可及性 → TAD；先理解基因为何需要调控，再理解三维组织。
- 同步跨物种主线：细菌 lac 操纵子、植物质壁分离/气孔、酵母出芽/发酵、草履虫伸缩泡/摄食、噬菌体完整裂解周期。
- 共同机制后续重点：DNA 复制、RNA 加工、ATP 合酶、膜运输和细胞分裂比较。
- TAD 是接触结构域，不是有膜小室；环挤出不等于所有表达变化。植物采用物种明确的三维基因组案例，不照搬哺乳动物 CTCF 机制。
- 每个候选开工前需固定物种与实验范围，写明可操作条件和可观察输出。没有定量模型时使用定性趋势，不能伪造表达倍数或真实反应速度。
