# BioScape 全站性能检查与优化 · 2026-10-04

本轮以已发布的 `ae697be` 为冻结基线，覆盖首页启动、模型加载/切换、9 类结构、84 个生物学过程的 235 个根模型/条件组合、拾取、标注、场景释放和影像工作台。每个过程均已审查和测量；实现集中于实际重复工作，保留无需改动的路径。不是每个过程都获得相同收益。

## 全量 CPU 对照

独立串行 Node 进程按旧版→新版→新版→旧版执行。每个条件先运行 31 个预热姿态，再采样 121 个均匀前向姿态、注册阶段及非均匀往返 seek。两轮均值比较，共 940 个病例执行，0 错误；235 个病例的节点/网格/顶点/索引/实例和缓冲容量统计完全一致。完整轨迹及原始时长保留在本地证据。

235 个组合等权平均更新耗时 **0.861 → 0.599 ms，减少 30.4%**。这不是流量加权体验指标，也不是 FPS 提升。重复相同姿态单独记录，未用于以上收益计算。

## 浏览器测量与发布状态

15 个代表性与对照过程按 AB/BA 顺序运行 60 次真实播放窗口，每次从进度 .31、1.5 倍速播放 2.4 秒，0 错误。此处为短窗口，完整轨迹由前述 235 条件扫描覆盖。分泌更新耗时 4.716→0.931 ms，伸缩泡 3.856→2.008 ms，纤毛 9.577→7.776 ms；DNA 修复窗口约增加 0.063 ms，其余控制与所有原始记录均保留。草履虫接合和胞间连丝在这个窗口的静态曲面收益不代表整个周期；完整周期以 CPU 表为准。浏览器帧间隔均约 16.67 ms，不宣称 FPS 提升。

最终九类结构按 AB/BA 顺序完成 72 次浏览器测量，0 错误。每类每版包括两次 prepared-model 缓存冷启动和两次立即再次打开；每次准备后开启标注并旋转 1.8 秒。HTTP/模块缓存已预热，ready 包括模型准备、场景设置和两帧显示；探针以 40 ms 轮询 readiness，短延迟差异受其量化影响。这是同一 Apple M1 / 16 GiB 浏览器上的有限样本，不是跨设备、首次网络访问或实际用户分布的结论。

| `plant` | 2081.4 → 2130.9 | 244.1 → 216.3 |
