## 本轮发现与修复

1. **比较视角彻底独立。** 移除联动按钮、相机传播与复合相机接口；旋转、缩放和复位只作用于对应模型。旧分享链接即使带 `sync: true` 也不能恢复同步，两侧已有视角仍各自保留。
2. **点击当前比较主题不会清空操作。** 已选模型对再次选择同一主题保持原模式、标注、拆解程度和相机，不重新加载。
3. **刷新保留当前探索状态。** 结构相机、显示设置和过程进度、速度、条件、标注统一更新当前场景链接；离开页面时保存最后状态，修复操作后立即刷新回退到旧快照。
4. **各模型分别记住最近过程。** 在动物与植物等根模型之间切换后，各自的“继续过程”仍返回该模型此前的过程与进度。
5. **选模弹窗的 Escape 只关闭弹窗。** 焦点移到分类按钮后按 Escape 不再意外退出整个比较；关闭后焦点回到模型入口。
6. **内部标注遵循模型显示模式。** 完整外壳下隐藏被外壳遮住的内部结构标签；剖面／拆解按模型定义显示。规则同时作用于实时画面和导出，并经过优化、worker 打包与还原链路验证。全无可见标注时按钮禁用并解释原因，切回剖面保留原偏好。
7. **影像工作台保留已完成录像。** 再次点击当前画幅、背景等选项不再清空录像；真正改变配置才重新生成。完成后的提示与实际录像状态一致。
8. **搜索优先直接命中。** 局部结构自身名称的匹配优先于祖先名称匹配；英文搜索 `myelin` 首项为 Myelin internodes，同时保留按所属模型搜索的能力。
9. **比较工具栏在窄屏更紧凑。** 主题横向滚动与交换按钮共用一行；320／390px 布局、搜索弹窗与工作台可使用且无页面横向溢出。
10. **说明与新增内容一致。** 关于页补齐九类完整模型，神经元核副标题改为中性的“局部放大”，避免整体视图／导出仍被叫作剖面。
