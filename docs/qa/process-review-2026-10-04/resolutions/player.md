# Shared player cadence repair

Display-frame model updates read the authoritative progress ref independently of throttled React text/session publication. Paused views remain demand-rendered and geometry work is cached. Pause, seek, condition change and scene disposal synchronously cancel the clock. Capture temporarily seeks and restores the live pose.

Focused and independent checks pass. The first mounted transcription measurement produced 1681 updates across the 28-second 1x timeline (60.0004 updates/s, no backwards updates, terminal exactly 1). See `evidence/player/browser-cadence-summary.json`, raw `evidence/browser/shared-player-transcription-1x.json`, and the independent review. This measures model updates in one desktop development environment; it is not a mobile or universal GPU benchmark. Integrated native interaction acceptance is recorded separately.
