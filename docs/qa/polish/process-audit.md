# Process rendered audit — 2026-10-03

84 processes / 503 teaching-stage entry frames were actually visually inspected at 1280 × 720. These are actual browser renders through CUA, saved individually and inspected in per-process contact sheets. The first seven process sequences use the active 5174 build; remaining sequences use the stable 4197 build. No viewport override was changed by this reviewer.

This is **not** exhaustive animation or scientific acceptance: between-stage motion continuity, timeline endpoints, alternative conditions, source-link interaction, mobile/device behavior, remain outside this review scope; final default-stage label regression is now complete. Stage entry frames do not necessarily show the stage final event.
