## 审查中实际修复的问题

- 红细胞、神经元、肌纤维局部重建；髓鞘末端、轴突连通、肌节 H 区／中央无头区、双膜和管腔用实际几何验证。
- 蛋白酶体增加四层七聚体实体，修复新外沟槽贯穿内壁的回归；保留外层沟槽而闭合催化腔，并清除末态底物及空标签。[最终证据](proteasome.md)
- 自噬和内吞融合后的多边形轮廓改为连续曲面，融合颈、膜内腔和受体锚点同步核对。[融合记录](fusion.md)
- 后随链聚合酶切换增加简化的解离／再招募；酵母囊泡、分核 DNA、草履虫大核颗粒消除可见跳变，并核验核膜内包容。[A 源码审计](process-continuous-a.md) · [C 源码审计](process-continuous-c.md)
- 有丝／减数分裂在特定非规则进度发生的浮点射线漏交导致场景销毁，改为真实表面附着点随矩阵变换；精确失败进度、密集接触测试、重复完整播放全部通过。最终 4201 独立复验完成。
- 中文短词不再被当作分子符号直接压在模型上；无 ATP、未附着等对照增加实际响应，正常章节明确标为机制参考，导出标题也使用响应摘要。
- 合并过程工具栏，使 1280×720 下伸缩泡画布由 278.5 px 增至 324.5 px 高；保留完整皮层和排水范围，细管仍可缩放近看。[最终取景](root-contractile4201.jpg)
- 透明导出地面伪影、深色引导线低对比度、比较图标题过小、MP4 原生解码不兼容已修正。
