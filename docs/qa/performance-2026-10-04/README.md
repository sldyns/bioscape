# 保留模型精度的底层性能优化 · 2026-10-04

本轮优化在已经完成的 [84 个过程、164 项科学与播放修复](../process-review-2026-10-04/README.md)之上进行。冻结基线包含全部这些修复，因此性能差异不混入旧科学模型和新科学模型的差异。网格密度、分子细节、材质、光照、像素比、标签和动画时间线保持原有输出。

## 实际改动

- **连续膜生成**：固定网格拓扑、复用有向边交点与法向量、跳过不产生三角形的同号立方体，并复用数组。保留浮点运算顺序和完整输出缓冲区。详见 [signals](signals.md)。
- **内吞与自噬膜**：检查完整膜轮廓，仅在有效轮廓变化时重建几何、法线、边界和脂质实例；固定三角函数预计算。详见 [traffic](traffic.md)。
- **分裂几何**：利用既有精确 x 对称性减半膜场采样；染色体直接查询静息坐标，取消每帧先清零再变形的中间重建。详见 [division](division.md)。
- **共享渲染**：相同输入复用结构取景距离；隐藏过程标签时停止标签布局，显示、语言、字体和尺寸变化正确失效。方向拟合与导出仍调用原计算。详见 [renderer](renderer.md)。

连续膜缓存是有界内存换计算：凋亡约 8.29 MB、分化约 8.68 MB 的固定 typed-array 存储（包含输出缓冲区、采样和拓扑缓存）。未测量旧实现的完整堆占用，不能把该改动描述为内存减少。

## 性能测量

同一台 macOS arm64 机器，Node v22.22.1。CPU 单进程先分别预热，再进行四轮 181 个进度点的 AB/BA 顺序对照；原生浏览器使用真实 `ProcessExperience` 的播放按钮，以 1.5× 完整播放，各版本两次，顺序为 A/B/B/A。浏览器计时期间没有截图导出、整仓测试或代理并行测试。原始长间隔全部保留，不剔除慢帧。
