# README covers

`home-en.png` and `home-zh.png` are unaltered 1280 × 720 browser captures of the current BioScape homepage, taken on 2026-10-04 from the production build at application commit `d559d964bed541e4f6750df71b343c3d44934f1e`. Each uses the matching interface language and the live animal-cell preview. No generated imagery, model substitutions or resolution reduction was used.

The README model gallery reuses the nine original renders in [`public/home/models`](../../../public/home/models/); see their [provenance](../../qa/homepage/assets.md). The structure and transcription illustrations remain the existing localized application captures in [`../en`](../en/) and [`../zh`](../zh/).

Both GitHub attachment video URLs are preserved as bare URLs inside expandable sections, so GitHub continues to render native players. For film sources and licensing, see [media production](../../../scripts/media/README.md).
