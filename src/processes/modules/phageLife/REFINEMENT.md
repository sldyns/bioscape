## Screenshot correction: host membrane bristles

Root screenshots of `phageLysogenic` (0.24) and `phageLytic` exposed an actual instancing defect: the first lipid tail normalized a shared direction vector in place, so the second tail incorrectly used length 1. That produced radial bristles. Both tails now use an immutable measured length and run from their own leaflet to the exact bilayer midpoint; each is only 0.01036–0.0224 scene units long. Their two axial offsets stay inside the phospholipid headgroup width. No external host hairs were retained.

The scoped smoke now checks every lipid-tail instance: cylinder height below 0.023, and both centerline endpoints inside its paired membrane leaflets. All five models pass this and the existing checks. Corrected screenshots still require root re-capture; no browser was used here.
